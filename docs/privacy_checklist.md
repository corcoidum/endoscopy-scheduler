# 개인정보보호 점검 체크리스트

- [ ] 직원별 개인 계정 사용
- [ ] 공동 계정 금지
- [ ] 퇴사자 계정 삭제 대신 비활성화
- [ ] 환자정보 최소 입력 확인
- [ ] 주민등록번호, 주소, 검사결과, 결제정보 미저장
- [ ] 감사 로그에 환자 이름과 연락처가 반복 저장되지 않음
- [ ] 외부 분석/광고 스크립트 없음
- [ ] 환자정보를 외부 AI API로 전송하지 않음
- [ ] 백업 파일 암호화
- [ ] 백업 복구 테스트 완료
- [ ] 운영 DB와 개발 DB 분리
- [ ] 내부망 TLS 또는 VPN 적용
- [ ] 화면 출력/캡처 권한 정책 수립
