# 직원용 사용 매뉴얼

## 오늘 일정

- 첫 화면에서 오늘 예약, 준비 미확인, 완료 수를 확인합니다.
- 환자 상태 변경 전 이름과 차트번호를 다시 확인합니다.
- 상태 변경 순서: 예약 → 내원 → 검사 진행 → 검사 완료

## 예약 등록

1. 예약 날짜와 시간을 선택합니다.
2. 차트번호와 환자 이름을 입력합니다.
3. 검사 종류와 수면 여부를 선택합니다.
4. 준비 안내 여부를 선택합니다.
5. 특이사항은 꼭 필요한 업무 정보만 적습니다.
6. 저장 후 상세 화면에서 날짜, 시간, 차트번호를 확인합니다.

## 예약 취소

- 취소 사유를 반드시 입력합니다.
- 예약은 삭제하지 않고 상태를 “취소”로 바꿉니다.

## 개인정보 주의

- 주민등록번호, 상세 주소, 검사 결과, 카드정보를 입력하지 않습니다.
- 약제 중단 여부는 앱에서 판단하지 않고 원장 또는 EMR 확인으로 처리합니다.
